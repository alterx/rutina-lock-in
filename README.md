# Rutina Lock In

PWA para seguir la rutina de 3 días Full Body + Rucking: registro de pesos y ligas por serie, temporizador de descanso, progreso por ejercicio y check-in semanal.

Todos los datos se guardan solo en el dispositivo (localStorage). Desde la pestaña Guía se puede exportar e importar un respaldo.

Basada en la metodología The Great Lock In de Coach William Holman.
